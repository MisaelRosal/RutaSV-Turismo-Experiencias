RESUMEN DEL PROYECTO - RutaSV / IguanaSV (Turismo y Experiencias en El Salvador)
==============================================================================

Plataforma web full-stack para publicar y reservar experiencias de turismo en El Salvador.
Estado actual: esqueleto funcional, paginas placeholder.

ESTRUCTURA
----------
Frontend/   React 19 + Vite 8 + Tailwind 4 (npm)
Backend/    .NET 9 API (C#) - IguanaSV.Api
database/   schema.sql + dump de PostgreSQL 16
docker-compose.yml  (Postgres + MinIO + Backend + Frontend + pgAdmin)
.env        credenciales de infraestructura

FRONTEND (React + Vite + Tailwind)
----------------------------------
- Rutas (src/App.jsx): / catalogo, /experiencias/:id ficha, /login auth, /reservas, /panel operador
  - todas con layout comun (Header + Footer).
- Datos mock (src/data/seed.js): 6 experiencias (surf El Tunco, cafe Apaneca, hostal Suchitoto,
  ruta pueblos vivos, glamping, volcan Santa Ana), 5 departamentos, 7 categorias con imagenes de Unsplash.
- Servicios (src/services/experiencias.js): filtros por busqueda/categoria/departamento/tipo con delay simulado.
- Hook useExperiencias.js con estados carga/error.
- Paginas de detalle, auth, reservas y panel son placeholders ("Aqui ira...").
- Carpeta src/maps/ VACIA (se planea Leaflet, aun no instalado).
- Verificado: npm install OK, build OK, dev server OK.

BACKEND (.NET 9 API)
--------------------
- Program.cs: EF Core + PostgreSQL (Npgsql), OpenAPI, endpoint /weatherforecast de plantilla.
